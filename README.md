# SOS-013: расписание задания оптимизации дедупликации и объем неоптимизированных данных

Скрипты, исходные данные и протокол эксперимента к статье «Влияние расписания задания оптимизации дедупликации на объем неоптимизированных данных» (Гольцман М.Э., Гаевский Р.А., РГУ нефти и газа (НИУ) имени И.М. Губкина, кафедра БИТ, дисциплина «Современные операционные системы», 2026).

Исследуется, как периодичность запуска задания оптимизации дедупликации в Windows Server 2025 (ежедневно или еженедельно) влияет на объем данных, которые еще не обработаны заданием. Факторы: расписание (ежедневно / еженедельно) и интенсивность притока (2 и 6 ГБ/сут). Серия длится 14 модельных суток, выполнено 16 серий (n = 4 на комбинацию).

## Состав

| Папка | Содержимое |
|---|---|
| `scripts/` | `01-Host-CreateVM.ps1` (создание ВМ Hyper-V), `02-Host-DeployToVM.ps1` (подготовка стенда и контрольная точка Base), `03-Host-RunAll.ps1` (проведение серий), `Dedup-ScheduleExperiment.ps1` (гостевой скрипт: настройка дедупликации, приток, замеры, WSB), `analyze_results.py` (статистика и рисунки) |
| `data/` | объединенные данные 16 серий: `runs.csv` (128 запусков задания), `events.csv`, `wsb.csv`; `stand_status.txt` (состояние стенда после подготовки) |
| `data/series_raw.zip` | исходные папки всех серий (`runs.csv`, `events.csv`, `wsb.csv`, `meta.json`, `progress.log`, `done.txt`) и пробная серия `results_smoke` |
| `analysis/` | `summary.csv`, `summary.txt`, `stats.txt`, рисунки 6-8 статьи |
| `docs/` | протокол воспроизведения |

Серии `Daily_2GB_r3`, `Daily_2GB_r4`, `Daily_6GB_r2` выполнены с 4 ГБ ОЗУ ВМ (остальные с 8 ГБ), см. `meta.json` и раздел 5 протокола.

## Воспроизведение

Требуется хост с Hyper-V, около 300 ГБ свободного места на диске F: (NTFS), образ Windows Server 2025, Windows PowerShell 5.1 от имени администратора. Подробно с ожидаемым результатом каждого шага: `docs/Протокол_воспроизведения.pdf`.

```powershell
cd F:\SOS-013\scripts
.\01-Host-CreateVM.ps1 -IsoPath 'F:\ISO\WS2025.iso'      # затем установить Windows Server 2025
$c = Get-Credential Administrator
.\02-Host-DeployToVM.ps1 -Credential $c
.\03-Host-RunAll.ps1 -Credential $c -Smoke                 # пробная серия
.\03-Host-RunAll.ps1 -Credential $c -Repeats 4             # 16 серий (в статье)
```

Обработка (Python 3, `pip install -r requirements.txt`):

```
cd data
tar -xf series_raw.zip          # или распаковать архив вручную
cd ..
python scripts/analyze_results.py --results data/results --out analysis
```

## Основной результат

| Приток | Ежедневно, медиана, ГБ | Еженедельно, медиана, ГБ | Отношение (Х-Л) |
|---|---|---|---|
| 2 ГБ/сут | 1,97 | 14,31 | 7,16 |
| 6 ГБ/сут | 5,98 | 42,00 | 7,07 |

Стратифицированный перестановочный тест по обеим интенсивностям: p = 0,0004. При n = 4 отдельные сравнения после поправки Холма не значимы (p = 0,057), поэтому выводы предварительные. Подробно в `analysis/stats.txt`.
